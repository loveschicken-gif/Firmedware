# Security policy

Firmedware’s security model, repository safety rules, threat model, and production checklist are documented in **[docs/SECURITY.md](docs/SECURITY.md)**.

For where firm data is stored (GitHub vs PostgreSQL vs external documents) and how multiple users share one deployment, see the main **[README.md](README.md)** sections [Code vs Data vs Documents](README.md#code-vs-data-vs-documents) and [Do Not Commit Secrets or Firm Data](README.md#do-not-commit-secrets-or-firm-data).

To report a security issue, contact the maintainers listed in the repository (do not open public issues with vulnerability details).
