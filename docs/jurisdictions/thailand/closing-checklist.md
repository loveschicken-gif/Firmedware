# Matter closing checklist (Thailand) / เช็กลิสต์ปิดงาน/คดี (ไทย)

> **Bilingual / สองภาษา:** Each section is English first, then Thai (`ภาษาไทย`). Checklist items: English line, then indented Thai.

Operational checklist when moving a matter to **ปิดงาน** / **Closed** or **เก็บถาวร** / **Archived**. Firm lawyers should customize per practice area.

**ภาษาไทย:** เช็กลิสต์ปฏิบัติการเมื่อย้ายงาน/คดีไป **ปิดงาน** / **Closed** หรือ **เก็บถาวร** / **Archived** ทนายความในสำนักงานควรปรับตามสายงาน

## Work and documents / งานและเอกสาร

- [ ] All material tasks marked complete or cancelled
  - [ ] งานสำคัญทั้งหมดทำเสร็จหรือยกเลิกแล้ว
- [ ] Final advice letter / memo sent (if applicable)
  - [ ] ส่งหนังสือคำปรึกษา / memo ฉบับสุดท้ายแล้ว (ถ้ามี)
- [ ] Final documents linked in Firmedware (titles + external URLs)
  - [ ] ลิงก์เอกสารสุดท้ายใน Firmedware (ชื่อ + URL ภายนอก)
- [ ] Signed copies received and linked (สัญญาลงนามแล้ว, คำสั่งศาล, etc.)
  - [ ] ได้รับและลิงก์สำเนาที่ลงนามแล้ว (สัญญาลงนามแล้ว คำสั่งศาล ฯลฯ)
- [ ] Court/agency copies filed and linked where relevant
  - [ ] ยื่นและลิงก์สำเนาต่อศาล/หน่วยงาน ตามความเกี่ยวข้อง

## Client and billing / ลูกความและการเรียกเก็บเงิน

- [ ] Client notified of closure scope
  - [ ] แจ้งลูกความขอบเขตการปิดงานแล้ว
- [ ] Outstanding invoices issued or waived per firm policy
  - [ ] ออกใบแจ้งหนี้ค้างหรือยกเลิกตามนโยบายสำนักงาน
- [ ] Payment / withholding tax / VAT notes recorded (external accounting or future billing module)
  - [ ] บันทึกการชำระ / ภาษีหัก ณ ที่จ่าย / VAT (บัญชีภายนอกหรือโมดูลเรียกเก็บในอนาคต)
- [ ] Retainer balance reconciled
  - [ ] กระทบยอดเงินประกันแล้ว

## Access and confidentiality / การเข้าถึงและความลับ

- [ ] Matter assignments reviewed; remove unnecessary users/groups
  - [ ] ทบทวนการมอบหมายงาน/คดี ลบผู้ใช้/กลุ่มที่ไม่จำเป็น
- [ ] Google Drive / OneDrive / SharePoint / Dropbox permissions reviewed
  - [ ] ทบทวนสิทธิ์ Google Drive / OneDrive / SharePoint / Dropbox
- [ ] Local folder access reviewed for departing staff
  - [ ] ทบทวนสิทธิ์โฟลเดอร์ภายในสำหรับพนักงานที่ลาออก
- [ ] High-sensitivity documents tagged correctly in Firmedware
  - [ ] ติดแท็กเอกสารความลับสูงถูกต้องใน Firmedware

## Records / บันทึกและการเก็บรักษา

- [ ] Closing note added to matter `notes`
  - [ ] เพิ่มบันทึกปิดงานใน `notes` ของงาน/คดี
- [ ] Workflow status set to closed/archived final status
  - [ ] ตั้งสถานะ workflow เป็นปิดงาน/เก็บถาวร (สถานะสุดท้าย)
- [ ] Retention period noted per firm policy (limitation, PDPA, tax)
  - [ ] บันทึกระยะเก็บรักษาตามนโยบาย (อายุความ PDPA ภาษี)
- [ ] Activity log spot-check for unusual exports near closing date
  - [ ] สุ่มตรวจบันทึกกิจกรรมเรื่องการส่งออกผิดปกติใกล้วันปิด

## Cross-border / special matters / ข้ามพรมแดน / งานพิเศษ

- [ ] Immigration / corporate registry follow-ups completed
  - [ ] ติดตามงานตรวจคนเข้าเมือง / ทะเบียนนิติบุคคลเสร็จแล้ว
- [ ] PDPA data minimization review if matter involved sensitive personal data
  - [ ] ทบทวนการลดข้อมูล PDPA หากงานมีข้อมูลส่วนบุคคลละเอียดอ่อน
- [ ] No confidential matter data retained in personal AI chat histories
  - [ ] ไม่เก็บข้อมูลลับของงาน/คดีในประวัติแชท AI ส่วนตัว
